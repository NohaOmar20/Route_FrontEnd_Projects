
# Project: Noha Omar - Front-End Developer Portfolio

A clean, professional portfolio website built using **pure HTML** and **inline CSS**. This project demonstrates structural layout techniques using HTML Tables to organize content without the need for external CSS frameworks.

## 🚀 Project Overview

This portfolio is divided into three main sections, each showcasing different HTML structural capabilities:
1.  **About Me:** A profile overview using nested tables.
2.  **Experience Timeline:** A complex data representation using advanced table attributes.
3.  **Contact Me:** A functional, well-aligned form grouped by logical fieldsets.

---

## 🛠 Technical Implementation

### 1. About Me Section
* **Layout:** Utilizes a `100%` width table to split the screen into a `30%` (profile) and `70%` (biography) column.
* **Social Integration:** Social media icons are organized within a **nested table** inside the profile cell to ensure perfect alignment.
* **Skill List:** Uses an unordered list (`<ul>`) styled with inline CSS to match the professional theme.

### 2. Experience Timeline
This section demonstrates mastery over complex HTML table structures:
* **Structural Tags:** Utilizes `<thead>`, `<tbody>`, and `<tfoot>` for semantic organization.
* **Cell Manipulation:** Implements `rowspan` to group multiple roles under the same company and `colspan` for the total experience summary in the footer.
* **Styling:** Uses `cellspacing="0"`, `border-collapse`, and `bgcolor` attributes to create a sharp, modern professional table look.

### 3. Contact Form
* **Grouping:** Used `<fieldset>` and `<legend>` tags to logically separate "Personal Information" from "Project Details."
* **Alignment:** Instead of standard CSS Flexbox/Grid, an internal table structure was used inside the form to align labels and input fields into a balanced 4-column grid.
* **Accessibility:** Every input is connected to a specific `<label>` via `id` and `for` attributes to ensure high accessibility and user experience.
